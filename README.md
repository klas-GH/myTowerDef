# myTowerDef

A lightweight, mobile-first tower defense mini-game.

- Version: 1.5.0
- Run: open index.html in a browser (or use Live Server)
- Controls: Build (50 coins) on green spot, Start Wave, Restart
- Wave preview: the wave panel shows the next wave's HP, speed, enemy count, and reward before you start it.
- Assets: index.html, style.css, game.js, icon.svg, manifest.json, sw.js
