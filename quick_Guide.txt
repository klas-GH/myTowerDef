Quick Guide - myTowerDef v1.9.7

1. Run it
Save files in same folder. Open index.html in browser.
If local files blocked, use VS Code Live Server.

2. How to play
- Pick a tower type (Archer 50, Cannon 90, Magic 80) from the picker.
- Tap a green spot on the field to place it.
- Tap an existing tower to select and upgrade it, or Sell it for a full refund.
- Tap Start Wave to begin.
- Targeting: tap a tower to select it, then change its target priority (First, Strongest, Fastest, Nearest) on the upgrade panel. Free to change; affects which enemy it attacks next.
- The wave panel shows the next wave's enemy types and counts before you start it.
- Enemy types: Standard (red), Runner (fast, low HP), Armored (slow, high HP).
- Defend base with 6 starting lives. Survive all waves to win (+coins per wave).
- Restart to play again.

3. Notes
- Mobile-first responsive layout with touch input.
- Offline-capable via service worker.
- Towers can be upgraded up to level 3.
