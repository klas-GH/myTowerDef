=== v 2.3.3 ===
- Fixed header overflow on narrow phones: the header is locked to a single row and the title, subtitle, and stats shrink via clamp() so they never wrap or overflow the viewport, even on the narrowest screens.
- Removed the @media (max-width: 380px) override since the clamp values already handle small screens.

It now calls draw() directly, so the themed backgrounds and unit icons appear as soon as they load, even on the title screen.
- Added 6 regression checks asserting the one-row header behavior (header_one_row, header_title_nowraps, header_stats_nowraps, header_no_narrow_media_query) and the scheduleRedraw/draw wiring (scheduleRedraw_calls_draw, scheduleRedraw_not_update).

=== v 2.3.2 ===

- The game draws the background PNG as the base layer in draw(), with the existing ground fill and procedural theme decorations drawn on top so the canvas never shows a blank frame while the PNG loads.

Each is a small 28x28 RGBA icon drawn with distinct silhouettes (round body for Standard, sleek diamond with speed streak for Runner, heavy hexagon with plate line for Armored, crowned boss body for Boss, bow for Archer, barrel for Cannon, crystal facet for Magic).

- Assets are loaded lazily and cached (loadBg/loadUnit) so repeated draws do not re-decode.

=== v 1.9.0 =====
- Introduced configurable tower targeting. Every placed tower carries its own `targeting` mode (default "first"); the mode only affects which enemy is acquired next and never changes a tower's cost, damage, range, or cooldown.
- Four targeting modes, each with a clear, distinct definition and deterministic tie-breaking: First (the living enemy furthest along the path, using the authoritative `point` field), Strongest (highest current HP), Fastest (highest movement speed), and Nearest (closest by Euclidean distance).
- Target selection only considers living enemies inside the tower's effective attack range; dead, reached-base, and out-of-range enemies are excluded. Empty enemy lists return null safely.
- Added a compact 4-button targeting picker inside the selected-tower panel that shows the current mode and lets the player switch freely, without spending currency or granting extra attacks. The picker is hidden when no tower is selected and fits narrow mobile screens.
- Targeting works identically for all supported tower types (Archer, Cannon, Magic); upgrades preserve the mode; selling a tower removes its targeting state; restart restores the default "first" mode for new towers.
- Combat, cooldown, projectile lifecycle, per-type enemy rewards, base damage, wave progression, victory, and defeat behavior are unchanged.
- Extended regression.js with deterministic target-selection, tower-integration, combat, and game-state tests for v1.9.0.
